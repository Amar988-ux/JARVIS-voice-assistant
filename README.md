# JARVIS-PY 🤖

**JARVIS-PY** is a local-first AI voice assistant built with Python. It combines voice recognition, text-to-speech, local language models, semantic memory, document search, and Windows automation to provide a practical desktop assistant.

## ✨ Features

* 🎙️ **Voice Interaction:** Speak naturally and receive spoken responses.
* 🧠 **Local AI:** Run language models locally using Ollama.
* 💾 **Semantic Memory:** Store and retrieve relevant information.
* 📄 **PDF Document Search:** Find relevant information in PDF documents using retrieval-augmented generation (RAG).
* 🖥️ **Windows Automation:** Perform supported desktop actions.
* 🌐 **Online and Offline Speech Recognition:** Use Google speech recognition online and Vosk for offline recognition.
* ⏰ **Smart Reminders:** Set reminders using natural language.
* 🛠️ **Extensible Plugins:** Add custom tools to expand the assistant's capabilities.
* 🎨 **Desktop HUD:** Optional futuristic interface with streaming captions and interruption controls.

## 🧰 Technology Stack

* Python 3.10+
* Ollama and Phi-3
* SpeechRecognition
* pyttsx3
* Vosk
* openWakeWord
* FAISS
* PyAutoGUI
* PyWebView

## 🚀 Getting Started

1. Install Python 3.10 or later.
2. Install Ollama and download the required model.
3. Clone or download this repository.
4. Install the required Python packages.
5. Start the assistant using `python app.py`.

Refer to the installation instructions below for the complete setup process.

## 📌 Project Information

JARVIS-PY is designed for local-first operation, with optional online services for web lookups and speech recognition. Some features require additional models, dependencies, or configuration.

See the full documentation for setup instructions, configuration options, available commands, and troubleshooting.
